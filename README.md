# 🖥️ IT Service Desk — Система заявок для системного администратора

Готовое веб-приложение для приема и обработки заявок сотрудников:
- Подача заявок: ФИО, кабинет, категория, приоритет, описание.
- Прикрепление фото: с камеры смартфона, из файлов, перетаскиванием (Drag & Drop) или вставкой скриншота из буфера обмена (**Ctrl+V**).
- Панель сисадмина с PIN-кодом (`1234`), живой статистикой, фильтрацией и звуковым оповещением.
- Мгновенные оповещения с фото в Telegram.
- Работает 24/7 в облаке без VPN.

---

## 🚀 Развертывание в Alwaysdata (24/7 бесплатно)

1. В терминале Alwaysdata (Web SSH):
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ> app
   cd app
   pip install --user -r requirements.txt
   ```
2. В разделе **Web ➔ Sites ➔ Edit**:
   - **Type:** User program
   - **Working directory:** `/home/ваш-логин/app`
   - **Command:** `python -m uvicorn main:app --host 0.0.0.0 --port $PORT`
3. Нажмите **Submit** и **Restart site**.
